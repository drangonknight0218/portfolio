  • Jan, 2022 - Aug, 2020
    eBay- Sr. Frontend Engineer

    As a Senior Frontend Engineer at eBay, played a critical role in developing eBay Live Shopping, a real-time, interactive shopping platform. The project heavily relied on React.js to build a dynamic and responsive user interfaces, where users could interact with live sellers and browse products in real time. Using React Hooks, managed state efficiently within functional components, leading to cleaner, more maintainable code. Additionally, integrated Redux for global state management, ensuring smooth, consistent data flow across components. For live updates and seamless interactions during events, used React with WebSocket, allowing real-time data to be displayed without refreshing the page. React's virtual DOM and component-based architecture ensured high performance and reusability, even with the complex, data-heavy nature of live shopping events. This project demonstrated the full potential of React in handling real-time user engagement at scale, improving company's overall shopping experience by merging streaming and e-commerce seamlessly.
